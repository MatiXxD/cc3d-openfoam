# Пример симуляции с dumper

Пример того, как можно реализовать вывод данных из CC3D. В данном примере создается класс `DumpSteppable`, который пишет в dump-файл состояние системы (т.е. для каждого пикселя пишет, какому типу клетки соответствует). Dump-файлы пишутся в формате `dump_{timestamp}.dat`.
